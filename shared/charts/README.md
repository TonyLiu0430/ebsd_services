# 共用圖表模組

此模組集中管理前端畫面與 PowerPoint 報告共同使用的粒徑分布 SVG 圖表及座標尺度計算。它是零相依的 ESM 模組，可直接由瀏覽器建置工具或 Node.js 使用。

- `src/`：CDF、一般直方圖、面積加權直方圖與座標尺度。
- `bin/render-grain-charts.mjs`：Python 報表透過標準輸入呼叫的 Node.js 介面。
- `tests/`：圖表尺度、SVG 與命令列輸出的同源驗證。

前端與 Python 後端映像應由同一個 Git 版本建置及部署，確保兩者包含相同版本的共用圖表。部署時可使用既有的 `IMAGE_TAG=sha-<commit>` 指定版本。

三角圖的繪製與報告中的其他折線圖目前仍有不同的版面需求，不在這次共用範圍內。
